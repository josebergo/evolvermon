# PRD 分册二 · ERP（主数据 / 销售 / 采购 / MRP）

> 域代码 `ERP` · ERP 在本产品中的边界：**围绕订单与计划的资源协同**（销售、采购、物料需求），财务只做成本数据出口，不自建总账。
> 遵循总册跨领域规范。

## 1. 执行摘要

ERP 分册交付三类能力：①制造业主数据（物料/BOM/工艺路线/工作中心/客商）；②交易单据（销售订单、采购订单）；③计划引擎（MRP）。它是 MES 与 WMS 的数据源头——没有 BOM 与物料，工单与库存无从谈起。

## 2. 问题陈述

- **谁**：销售、计划员（PMC）、采购员。
- **什么**：接单后靠经验判断"料够不够、产能行不行"；BOM 在工程师个人电脑里版本混乱；采购不知道真实缺料时间点。
- **痛**：交期承诺拍脑袋 → 逾期罚款；BOM 用错版本 → 整批报废；紧急采购溢价 20%+。
- **证据**：机加工细分行业访谈惯例痛点 🔶 Assumption（种子客户共创建模）。

## 3. 目标用户

主：计划员（MRP 运行者）；次：销售（订单录入）、采购（请购→订单）。

## 4. 战略背景

MRP 是"Excel 工厂"迁出的**第一理由**（手工算净需求是最高频加班场景），也是 Odoo/ERPNext 制造模块的心脏，优先级最高。

## 5. 方案概述

### 5.1 主数据域

1. **物料**：编码（自动/手工）、名称、规格型号、单位、类型（原料/半成品/成品/辅料/包材）、批次管理开关、安全库存、默认仓库、采购/制造属性（外购/自制）、状态。
2. **BOM**：父项物料 + 子项行（物料、用量、损耗率%）；版本（A/B/测试）、生效日期、状态（草稿/启用/停用）；同物料多版本，同时仅一个"当前启用"。
3. **工艺路线**：工序序列（工作中心、标准工时(准备/加工)、计件单价可选、外协标记）；挂在物料+BOM 版本。
4. **工作中心**：车间资源（名称、类型：人工/设备/产线、产能/班次、成本费率）。
5. **客商**：客户（编码、名称、联系人、收货地址多组、信用额度[S]）、供应商（编码、名称、联系人、交期、付款条件）。

### 5.2 销售域

销售订单：客户、行（物料、数量、单价、税率、交期）、状态机 `草稿→已审核→部分发货→已完成→关闭`；支持参照订单生成发货申请（转 WMS 出库）。

### 5.3 采购域

请购单（来源：手工/MRP 建议）→ 采购订单（供应商、行、交期）→ 到货通知（转 WMS 收货）。采购入库完成后回写采购订单行"已入库数量"。

### 5.4 MRP

- 输入：已审核销售订单（毛需求）+ 主生产计划 MPS[C]；库存（现有量-已预占）+ 在途（在途采购、在制工单产出）；BOM 展开。
- 输出：**计划订单建议**（生产建议→一键转工单；采购建议→一键转请购单）。
- 策略：按物料+日期合并净需求；低层码（LLC）处理跨层共用料；时间栅栏与安全库存参与计算[S]。

## 6. 成功指标

- 100 行 BOM 展开计算 < 1s（种子数据集）；
- MRP 建议被采纳率（一键转单/总建议）≥ 70%（信任度指标）；
- 订单录入到审核完成 ≤ 3 分钟（金路径）。

## 7. 功能需求

### 7.1 物料主数据（FR-ERP-001~010）
- FR-ERP-001 [M] 物料 CRUD + 列表（编码/名称/类型/状态过滤，分页）。
- FR-ERP-002 [M] 编码规则（自动编码：类别码+流水，可配置）。
- FR-ERP-003 [M] 物料详情聚合视图：BOM 引用（作为父/子）、库存快照、近期交易。
- FR-ERP-004 [M] 停用校验：存在未完结单据禁止停用。
- FR-ERP-005 [S] 单位换算组（采购箱/库存件）。
- FR-ERP-006 [S] 物料条码（一物多码：供应商码/内部码）。
- FR-ERP-007 [S] 安全库存告警列表（低于安全库存的物料汇总）。
- FR-ERP-008 [C] 多规格属性（颜色/尺寸矩阵 SKU）。
- FR-ERP-009 [C] 物料图片与附件。
- FR-ERP-010 [W] 批次策略引擎（有效期/先进先出自动规则，M2 做基础批次）。

### 7.2 BOM（FR-ERP-020~027）
- FR-ERP-020 [M] BOM CRUD（头+行），版本管理。
- FR-ERP-021 [M] 唯一"启用"版本约束（切换版本自动停用旧版并记录）。
- FR-ERP-022 [M] BOM 树形展开（多级）与父项反查（哪里用到）。
- FR-ERP-023 [M] 环引用校验（A 的子项含 A 的祖先 → 拒绝保存）。
- FR-ERP-024 [S] 复制 BOM（新版本起点）、成批替换子项。
- FR-ERP-025 [S] 用量/损耗率变更审计（联动审计日志）。
- FR-ERP-026 [C] BOM 成本滚动计算（最新价/移动平均价）。
- FR-ERP-027 [W] ECR/ECN 工程变更审批流（M5 轻量审批）。

### 7.3 工艺路线与工作中心（FR-ERP-030~036）
- FR-ERP-030 [M] 工作中心 CRUD（类型、班次日历、费率）。
- FR-ERP-031 [M] 工艺路线 CRUD（工序序列：序号、名称、工作中心、准备/加工工时）。
- FR-ERP-032 [M] 工艺路线挂物料（物料+BOM 版本维度）。
- FR-ERP-033 [S] 外协工序标记（转委外采购建议）。
- FR-ERP-034 [S] 工时单位（秒/分钟/小时）换算与校验。
- FR-ERP-035 [C] 工作中心产能负荷图（排产输入，M3）。
- FR-ERP-036 [W] 图形化工艺编辑器。

### 7.4 客户/供应商（FR-ERP-040~045）
- FR-ERP-040 [M] 客户 CRUD + 收货地址组。
- FR-ERP-041 [M] 供应商 CRUD（含交期、联系人）。
- FR-ERP-042 [S] 客户信用额度与超信用拦截[S]。
- FR-ERP-043 [S] 客商合并/停用（防重复建档）。
- FR-ERP-044 [C] 供应商评级（到货及时率/合格率，M4）。
- FR-ERP-045 [W] 供应商门户协同。

### 7.5 销售订单（FR-ERP-050~057）
- FR-ERP-050 [M] 订单 CRUD：头（客户、币种、税率、交期）+ 行（物料、数量、单价、行交期）。
- FR-ERP-051 [M] 状态机：草稿→审核→部分发货→完成→关闭；草稿可删，其后仅可作废。
- FR-ERP-052 [M] 审核校验：客户有效、物料有效、数量>0。
- FR-ERP-053 [M] 订单行库存快照（下单时显示可用量，含其他订单预占[S]）。
- FR-ERP-054 [M] 参照订单发起发货申请（生成 WMS 出库单草稿）。
- FR-ERP-055 [S] 订单变更记录（改量/改期审计+醒目提醒）。
- FR-ERP-056 [S] 部分发货自动回写（发货数量/未发数量）。
- FR-ERP-057 [C] 价格策略（客户等级价/阶梯价）。

### 7.6 采购（FR-ERP-060~068）
- FR-ERP-060 [M] 请购单 CRUD（来源：手工/MRP，状态：草稿→审核→已转采购/关闭）。
- FR-ERP-061 [M] 采购订单 CRUD（供应商、行、交期、税率）。
- FR-ERP-062 [M] 采购订单状态机：草稿→审核→到货中→部分入库→完成→关闭。
- FR-ERP-063 [M] 参照请购合并/拆分生成采购订单。
- FR-ERP-064 [M] 到货通知单（转 WMS 收货，收货完成回写已入库数量）。
- FR-ERP-065 [S] 到货差异提醒（超期未到列表）。
- FR-ERP-066 [S] 采购入库单价确认（财务可改，成本差异留痕）。
- FR-ERP-067 [C] 供应商比价（多家询价对比）。
- FR-ERP-068 [W] 采购发票勾稽三单匹配（对接财务后评估）。

### 7.7 MRP（FR-ERP-070~077）
- FR-ERP-070 [M] 手动触发 MRP 运算（按工厂/计划范围物料）。
- FR-ERP-071 [M] 净需求计算：毛需求(销售订单) −（现有−预占）− 在途 + 在制产出缺口；按 BOM 逐层展开。
- FR-ERP-072 [M] 低层码计算与共用料跨订单合并。
- FR-ERP-073 [M] 输出建议列表：生产建议（数量、建议开工/完工日）、采购建议。
- FR-ERP-074 [M] 一键转单：生产建议→工单草稿（自动带 BOM/工艺）；采购建议→请购草稿。
- FR-ERP-075 [S] 计划参数：安全库存、批量规则（直接/固定批量）、提前期参与计算。
- FR-ERP-076 [S] MRP 运行报告（需求来源穿透：这条建议来自哪张订单哪一层）。
- FR-ERP-077 [C] 定时自动 MRP + 变更重算（重生成/净改变）。

## 8. 用户故事（关键）

**US-ERP-01 接单即算料**：作为计划员，销售审核一张 500 件的订单后，我运行 MRP，系统给出"缺哪些料、缺多少、建议何时开工/下单"，以便 10 分钟内回复交期。
- AC1 毛需求含该订单全部行；AC2 现有量扣除其他已审核订单预占[S]/毛需求顺序扣减[M]；AC3 建议可一键生成工单与请购单，单据头带需求来源标记；AC4 计算过程可穿透（每条净需求的加减项列出）。

**US-ERP-02 BOM 版本切换不炸线**：作为工程师，我把 BOM 从 V1 切到 V2，正在执行的老工单仍按 V1 领料。
- AC1 已下达工单快照 BOM 版本（生成时固化）；AC2 新工单取"当前启用"版本；AC3 切换动作记录审计。

**US-ERP-03 采购闭环**：作为采购员，从 MRP 建议到供应商到货入库，我全程在一个界面跟踪。
- AC1 请购→采购→到货→入库四单据状态可从订单详情穿透查看；AC2 入库数量回写采购行；AC3 超交按参数拦截或放行（默认允许 5% 超收[S]/严格[M]）。

## 9. 不做清单

销售报价/CRM 线索、合同管理、应收应付账款台账、多币种汇率引擎、退货逆向流程（M3 再评估）。

## 10. 依赖与风险 / 开放问题

- 依赖：平台（租户/工厂上下文）、WMS（库存与收货）。
- 风险：MRP 计算正确性 → 以 Odoo 开源测试用例为蓝本建金数据集回归测试。
- OQ-1：预占发生在"审核"还是"下达"？（假设：审核即软预占，可参数化）🔶
- OQ-2：MRP 每次全量重算还是净改变？（M1 全量，物料数 ≤5000 时性能可接受）🔶
