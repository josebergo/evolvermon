# PRD 分册五 · 非功能性需求

> 域代码 `NFR` · 覆盖：性能与并发、可伸缩性、部署、安全、可靠性、可观测性、兼容性、可维护性、合规。

## 1. 性能与并发（Performance & Concurrency）

| 编号 | 需求 | 验收方式 |
|---|---|---|
| NFR-001 | 报工接口：单节点 200 并发持续 10min，P99 < 300ms，错误率 0 | 压测脚本入库 + CI 基线 |
| NFR-002 | 列表查询（10 万行级表、常规过滤+分页）P95 < 300ms | 种子数据集基准 |
| NFR-003 | 库存过账（含流水+回写+预占核销）事务内完成，P99 < 100ms，可串行化防超卖 | 并发单测：100 goroutine 同行出库不超发 |
| NFR-004 | MRP：5000 物料 + 500 订单全量计算 < 30s（4C8G） | 基准测试 |
| NFR-005 | 数据库连接池上限可配；慢查询（>500ms）自动记录 | 日志断言 |

## 2. 可伸缩性

- NFR-010 应用无状态（JWT + DB 会话），支持水平扩展（N 实例 + LB）。
- NFR-011 预留 Redis 接入位（缓存/分布式锁/队列），M2 起按需启用。
- NFR-012 单实例目标容量：50 并发用户/厂区、5 万物料、日 2 万单据。

## 3. 部署（多工厂形态）

- NFR-020 **三种部署形态**：①单机 Docker Compose（工厂内网，1 条命令）；②高可用 K8s（Helm Chart，M3）；③托管 SaaS（H1 商业包，多租户单实例）。
- NFR-021 版本升级：数据库迁移自动执行且**可回滚**（向前兼容两版本）；升级指南文档化。
- NFR-022 跨工厂拓扑：**每租户独立库**（默认，数据主权）或**共享库+tenant_id 过滤**（托管模式）二选一，由部署参数决定，代码同构。
- NFR-023 离线工厂支持：全部功能在无外网环境可用（字体/前端资源本地化）。

## 4. 安全（Security）

- NFR-030 密码 bcrypt(cost≥10)；传输 TLS（反向代理终止）；JWT RS256 签名。
- NFR-031 越权防护：所有业务 API 强制租户/工厂上下文注入；跨租户访问测试 0 通过为发布门禁。
- NFR-032 注入防护：ORM 参数化 + 输入校验层（validator）。
- NFR-033 敏感配置（DB 密码/JWT 私钥）走环境变量或密管，不入库不入 Git。
- NFR-034 审计日志不可删除（仅追加，DB 权限层面限制 UPDATE/DELETE）。
- NFR-035 依赖漏洞扫描（govulncheck + npm audit）进 CI。
- NFR-036 预留 PostgreSQL RLS（row-level security）启用开关（托管模式强制开启）。

## 5. 可靠性与数据完整性

- NFR-040 库存流水与台账同事务；每日对账 job（流水重算 vs 台账）0 差异告警。
- NFR-041 单据状态机乐观锁（version），冲突返回 409 + 最新数据。
- NFR-042 备份策略文档化：每日全量 + WAL 归档；恢复演练脚本。
- NFR-043 优雅停机（SIGTERM 排空连接），滚动升级不掉单。

## 6. 可观测性

- NFR-050 结构化日志（zap，JSON），含 trace_id/tenant/factory/user 上下文字段。
- NFR-051 /metrics 暴露 Prometheus 指标（HTTP 延迟分布、业务计数器：报工数/过账数/单据状态迁移）。
- NFR-052 /healthz /readyz 探针。
- NFR-053 前端错误上报（Sentry 兼容 DSN，可选）。

## 7. 兼容性

- NFR-060 浏览器：Chrome/Edge 最近两个大版本；PDA 端 Android WebView ≥ 90（PWA）。
- NFR-061 PostgreSQL 16+（仅使用 PG 特性：jsonb、部分索引、RLS 预留）。
- NFR-062 API 兼容承诺：v1 路径（/api/v1）语义化版本，破坏性变更走 v2。

## 8. 可维护性与二开体验（面向"小李"）

- NFR-070 代码结构遵循标准分层（见架构文档），新模块脚手架 `make new-module name=xxx`。
- NFR-071 核心 API OpenAPI 3 文档自动生成（swag 注解），与代码同仓。
- NFR-072 二开不改核心的扩展点：自定义字段（jsonb extra）、单据事件钩子（webhook）、报表 SQL 视图。
- NFR-073 单测覆盖率：核心域（库存/报工/状态机/MRP）≥ 80%，全量 ≥ 60%。
- NFR-074 中英双语文档结构（docs/zh、docs/en[M3]）。

## 9. 合规

- NFR-080 个人信息最小化：仅姓名/手机/邮箱，导出与删除接口（个保法）。
- NFR-081 Apache-2.0 合规：LICENSE 与 NOTICE 齐备，第三方依赖清单（SBOM）。

## 10. 不做

多活异地容灾、单元化架构、自有网关产品化（用 Nginx/Traefik 即可）。
