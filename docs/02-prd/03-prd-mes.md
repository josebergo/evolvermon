# PRD 分册三 · MES（工单 / 派工 / 报工 / 质量 / 看板）

> 域代码 `MES` · 定位：**工单从下达到完工入库的车间执行层**。不做设备数据采集（M6 前）。

## 1. 执行摘要

MES 分册管理工单全生命周期：接收 MRP/手工的生产建议 → 下达 → 按工序派工 → 扫码/工单报工 → 工序质检 → 完工 → 报交入库（转 WMS）。核心价值瞬间：车间主管第一次在电子看板上看到"每张工单此刻卡在哪道工序"。

## 2. 问题陈述

- **谁**：车间主管、班组长、操作工、质检员。
- **什么**：生产进度靠班组长口头汇报/白板；报工数据延迟一天且不可信；不良品混在合格数里一起报。
- **痛**：老板问进度要等 2 小时汇总；质量追溯靠翻纸单；计件工资月底吵翻天。
- **证据**：MES 开源赛道长期缺位（调研：mes4u 停更于 2020，Gitee 简易 MES 流程浅）——竞品缺失本身即证据。

## 3. 目标用户

主：车间主管（派工/看板）；次：操作工（PDA 扫码报工，字大步少）、质检员（移动检验）。

## 4. 战略背景

MES 是本产品**付费意愿最强**的模块（交期与质量=老板的钱），F2 实施包的主打场景；车间高并发报工是选择 Go 的核心论证。

## 5. 方案概述

### 5.1 工单模型

```
工单 WorkOrder（物料、数量、BOM快照、工艺快照、计划开/完工日、优先级）
  ├─ 工单工序 WOOperation（按工艺生成：工作中心、标准工时、状态）
  │    └─ 报工记录 Report（合格数/不良数/工时/操作工/设备[S]/备注）
  ├─ 领料/退料（转 WMS 出库/入库）
  └─ 质检记录 QCRecord（工序检 IPQC / 完工检 FQC）
状态：草稿→已下达→执行中→暂停→已完工→已入库→已关闭（+作废）
```

### 5.2 关键流程

1. **下达**：校验 BOM/工艺快照完整 → 生成工序行 → 可选预占材料[S]；
2. **派工**：把工序指派给班组/人（用户组），PDA 可见"我的任务"；
3. **报工**：扫码（工单号/工序码）→ 输入合格/不良/不良代码 → 校验工序顺序与工单状态 → 实时累计；
4. **完工**：末道工序合格数 ≥ 计划量（或手工强制完工）→ 状态"已完工" → 报交入库生成 WMS 成品入库草稿单；
5. **暂停/恢复/强制关闭**：均留痕，关闭时释放预占[S]。

### 5.3 质量

- 检验方案（物料级：抽检比例、检验项目、判定标准）；IQC（对接采购到货）、IPQC（工序报工触发[S]/手工[M]）、FQC（完工触发）。
- 不良代码字典（分类：外观/尺寸/功能…）；不合格处置：返工（生成返工工单[S]）/报废/让步放行[S]。

### 5.4 看板

- 车间大屏：在制工单甘特/状态墙、今日合格率/产量、异常清单（超期/暂停/不良超阈值）。

## 6. 成功指标

- 报工接口 200 并发持续 10 分钟，P99 < 300ms，0 重复计数（幂等键）；
- 工序进度实时性：报工到看板刷新 ≤ 5s（轮询/WS[S]）；
- 种子客户 4 周后纸单替代率 ≥ 80%。

## 7. 功能需求

### 7.1 工单（FR-MES-001~010）
- FR-MES-001 [M] 工单 CRUD（来源：MRP 建议/手工创建/销售直发[M]）。
- FR-MES-002 [M] 下达动作：固化 BOM/工艺快照、生成工单工序行、校验主数据有效。
- FR-MES-003 [M] 状态机（见 5.1）与乐观锁；作废仅限未报工。
- FR-MES-004 [M] 领料申请：按 BOM 快照生成建议领料行，参照生成 WMS 出库单。
- FR-MES-005 [M] 退料[M]与补料[S]流程。
- FR-MES-006 [M] 完工报交：末工序完工生成 WMS 入库草稿单（成品/半成品仓）。
- FR-MES-007 [S] 拆单/并单（大单拆两线生产）。
- FR-MES-008 [S] 工单优先级与插单（影响派工排序）。
- FR-MES-009 [S] 超期预警（计划完工日临近未完工→看板红牌）。
- FR-MES-010 [W] 返工工单自动生成链（M3）。

### 7.2 派工与执行（FR-MES-020~024）
- FR-MES-020 [M] 工序指派到用户组/个人（可批量）。
- FR-MES-021 [M] PDA"我的任务"列表（按工序状态过滤）。
- FR-MES-022 [M] 工序开始/结束动作（记录实际工时起止）。
- FR-MES-023 [S] 派工看板（按工作中心聚合负载）。
- FR-MES-024 [C] 有限产能自动排序（M3 排产）。

### 7.3 报工（FR-MES-030~036）
- FR-MES-030 [M] 工单+工序扫码报工（合格数、不良数、不良代码[多选]、备注）。
- FR-MES-031 [M] 报工校验：工单执行中、工序已派、前道工序已报、单次数量>0。
- FR-MES-032 [M] 幂等：客户端报文 token 去重，重复提交不重复计数。
- FR-MES-033 [M] 累计进度实时计算（各工序已报合格/计划量百分比）。
- FR-MES-034 [S] 计件工资视图（人×工序×单价汇总，导出）。
- FR-MES-035 [S] 离线容忍：PDA 断网暂存本地，恢复后补传（幂等保底）。
- FR-MES-036 [W] 设备数据自动报工（不做，见定位）。

### 7.4 质量（FR-MES-040~047）
- FR-MES-040 [M] 不良代码字典 CRUD（分类）。
- FR-MES-041 [M] 检验方案（物料级项目清单、抽检比例）。
- FR-MES-042 [M] 质检单（来源：完工/到货/手工）：逐项检验值录入、自动判定合格/不合格。
- FR-MES-043 [M] 不合格处置：返工/报废/让步（处置数量、原因）。
- FR-MES-044 [M] 质量追溯：按批次/工单/物料穿透（工单→报工→操作工→领料批次→供应商）。
- FR-MES-045 [S] 抽检规则（GB/T 2828 简化：按批量查样本量）。
- FR-MES-046 [S] 质量看板（合格率趋势、不良帕累托）。
- FR-MES-047 [C] 8D/纠正措施单（M4）。

### 7.5 看板与报表（FR-MES-050~053）
- FR-MES-050 [M] 在制工单墙（状态色块、进度、超期红牌）。
- FR-MES-051 [M] 今日产量与合格率（分工作中心）。
- FR-MES-052 [S] 工序级进度穿透（点工单看每道工序报工明细）。
- FR-MES-053 [C] 电子大屏轮播模式。

## 8. 用户故事（关键）

**US-MES-01 扫码三秒报工**：作为操作工，我在 PDA 扫工单二维码，选当前工序，输入"合格 48 / 不良 2"，点提交，3 秒内看到"已上报 ✓ 本工序累计 200/500"。
- AC1 未派工给我也允许报（参数：仅被派工人可报/开放班组报）默认开放；AC2 重复网络重试不双计；AC3 不良数>0 必须选不良代码；AC4 提交后返回最新累计进度。

**US-MES-02 完工自动待入库**：作为车间主管，末道工序报满后工单变"已完工"，仓管员的入库待办里出现报交单。
- AC1 完工生成 WMS 入库草稿（成品仓默认规则）；AC2 入库数量超完工数按参数拦截；AC3 状态流"已完工→已入库"由入库单审核驱动。

**US-MES-03 质量穿透**：作为质检员，客户投诉批次 B20261001，我 1 分钟内定位：工单→每道工序操作工→领用的原料批次→供应商。
- AC1 追溯链任一节点可点击穿透；AC2 导出追溯报告 PDF[S]。

## 9. 不做清单

设备联网采集（OPC/Modbus）、SPC 控制图、能源管理、安环 EHS、排产优化器（M3 做基础排产）。

## 10. 依赖与风险 / 开放问题

- 依赖：ERP（BOM/工艺/物料）、WMS（领料/入库）、平台（用户组/权限）。
- 风险：车间网络差 → 离线容忍（FR-MES-035）必须 M2 落地；报工作弊（代打卡）→ M5 设备指纹+摄像头[S]评估。
- OQ-1：工序强制顺序还是允许跳序？（假设：默认顺序强制，参数放开）🔶
- OQ-2：半成品是否强制入库再领？（假设：支持"过站直接流转"虚拟仓模式）🔶
