# PRD 分册四 · WMS（库存 / 出入库 / 移库 / 盘点 / 批次）

> 域代码 `WMS` · 定位：**账实一致的可追溯库存中心**。所有库存变动只通过单据驱动，流水不可篡改。
> 流程蓝本：ModernWMS（实战实施流程）+ GreaterWMS（API 化）+ 若依 WMS（中文单据习惯）。

## 1. 执行摘要

WMS 分册管理仓库-货位两级主数据与四类业务单据（入库/出库/移库/盘点），维护按批次（可选）的库存台账，输出账实相符的库存数据供 MRP、销售可用量计算。PDA 扫码是第一公民交互。

## 2. 问题陈述

- **谁**：仓管员（阿芳）、财务（对账）。
- **什么**：纸质单据漏记错记；月底盘点差异大且找不到原因；先进先出靠人脑；不良品与良品混放。
- **痛**：缺料停线找料 2 小时；财务月末对账加班；客户验厂查追溯超时。
- **证据**：wms-ruoyi/GreaterWMS 的高热度验证该痛点普遍；ModernWMS 自述"从商业 ERP 实施经验剥离"印证流程复杂度。

## 3. 目标用户

主：仓管员（PC+PDA 双端）；次：财务（只读对账）、计划员（可用量消费方）。

## 4. 战略背景

WMS 是数据底座（MES 领料、MRP 计算都吃库存数据），账实相符率是北极星护栏指标（<2%）。P3 细分（纯仓储企业）只需 WMS 模块即可服务——模块化裁剪的商业价值。

## 5. 方案概述

### 5.1 主数据

1. **仓库**（平台分册定义：挂工厂，5 类仓型）；
2. **货位**：仓库内 `库区-货架-层-位` 四段编码（可简化），属性（存储类型、容量[S]、是否冻结）；
3. **库存台账**：按 `工厂+仓库+货位+物料+批次` 维度存数量（可用/预占/冻结/不良），唯一索引防重；

### 5.2 单据类型与来源

| 单据 | 来源 | 状态机 |
|---|---|---|
| 入库单 RCV | 采购到货 / 生产报交 / 退货[S] / 盘盈 / 手工 | 草稿→执行中(逐行上架)→已完成 |
| 出库单 SHP | 销售发货 / 工单领料 / 报废 / 盘亏 / 手工 | 草稿→执行中(逐行拣货)→已完成 |
| 移库单 MV | 手工（含厂区间调拨：调出+调入两段） | 草稿→已完成 |
| 盘点单 STK | 周期计划/手工（全盘/抽盘） | 草稿→盘点中→差异→已调整 |

### 5.3 关键机制

- **流水驱动**：每笔变动写 `stock_movements`（类型/方向/数量/批次/单据引用/前后快照数量），台账金额由流水重算可校验；
- **预占**：销售审核/工单下达占用"预占量"，出库核销；
- **批次**：物料属性开关；入库生成批次号（规则可配），出库按 FIFO 建议[S]、强制校验[M 可配]；
- **负库存**：全局参数，默认禁止，出库校验可用量。

## 6. 成功指标

- 库存台账与流水重算校验脚本：每日 0 差异（自动化测试门禁）；
- PDA 扫码完成一次收货（扫单→扫物料→确认）≤ 15 秒；
- 盘点差异率 < 2%（种子客户 3 个月内）。

## 7. 功能需求

### 7.1 货位与库存（FR-WMS-001~009）
- FR-WMS-001 [M] 货位 CRUD + 树形浏览（仓库→库区→货位）。
- FR-WMS-002 [M] 库存台账查询（多维度过滤：工厂/仓/货位/物料/批次/状态量）。
- FR-WMS-003 [M] 库存明细穿透：任一行点击看该维度全部流水。
- FR-WMS-004 [M] 可用量计算口径统一接口：现有 − 预占 − 冻结 − 不良（供 MRP/销售）。
- FR-WMS-005 [S] 库存汇总报表（按物料/仓库聚合，导出 Excel）。
- FR-WMS-006 [S] 安全库存联动告警（与 ERP-007 同源）。
- FR-WMS-007 [S] 呆滞库存分析（N 月无动碰）。
- FR-WMS-008 [C] 库龄与批次效期预警。
- FR-WMS-009 [W] 序列号级库存（M2 做批次，序列号 Later）。

### 7.2 入库（FR-WMS-020~027）
- FR-WMS-020 [M] 入库单 CRUD（5 来源，见 5.2）；参照源单生成（到货单/报交单带出明细）。
- FR-WMS-021 [M] PDA 收货：扫单号 → 逐行扫物料/批次 → 输入数量/货位（默认上架策略[S]）→ 提交过账。
- FR-WMS-022 [M] 过账动作：逐行写台账+流水，回写来源单据（采购行已入库量/工单状态"已入库"）。
- FR-WMS-023 [M] 部分收货：允许分次执行，单据保持"执行中"直到全部行完成。
- FR-WMS-024 [M] 批次入库：自动生成批次号（规则：日期+流水）或扫供应商批次。
- FR-WMS-025 [S] 收货质检联动：IQC 待检量先入"待检"状态，检验合格转可用（对接 MES-042）。
- FR-WMS-026 [S] 上架策略（按物料默认仓/货位规则推荐）。
- FR-WMS-027 [W] ASN 高级预约（排车/月台）。

### 7.3 出库（FR-WMS-030~038）
- FR-WMS-030 [M] 出库单 CRUD（销售发货/领料/报废/盘亏/手工）。
- FR-WMS-031 [M] 参照生成：销售订单行→发货单草稿（可改仓）；工单 BOM 快照→领料单草稿。
- FR-WMS-032 [M] PDA 拣货：扫单→按行扫货位/物料/批次→数量确认→过账。
- FR-WMS-033 [M] 过账校验：可用量充足（负库存参数）、批次有效、货位不冻结。
- FR-WMS-034 [M] 出库回写：销售行已发数量、工单领料已领量。
- FR-WMS-035 [M] 预占核销：出库过账释放对应预占。
- FR-WMS-036 [S] FIFO 批次建议（拣货界面标"建议先出批次"）。
- FR-WMS-037 [S] 拣货缺料时转"欠料登记"[S]或领料申请退回计划员。
- FR-WMS-038 [W] 波次拣货/路径优化。

### 7.4 移库（FR-WMS-040~043）
- FR-WMS-040 [M] 厂内移库：选源货位维度库存→目标货位→过账（双流水）。
- FR-WMS-041 [M] 厂间调拨：调出仓"在途出库"+调入仓"在途入库"两段单据（在途仓模型）。
- FR-WMS-042 [S] 移库审核流（重要仓需确认）。
- FR-WMS-043 [W] 上架/补货自动化任务流。

### 7.5 盘点（FR-WMS-050~055）
- FR-WMS-050 [M] 盘点单创建（范围：仓库/货位/物料/批次，方式：全盘/抽盘）。
- FR-WMS-051 [M] 冻结快照：创建时锁定账面数（期间允许业务，差异按快照计算[S]；严格模式冻结库存[W]）。
- FR-WES-052 [M]（编号勘误：应为 FR-WMS-052）PDA 盲盘（不显示账面数）与明盘两种。
- FR-WMS-053 [M] 差异生成与调整：差异行自动生成盘盈入库/盘亏出库草稿，审核过账。
- FR-WMS-054 [S] 差异报告（按仓/人/物料类别统计差异率）。
- FR-WMS-055 [C] 循环盘点计划（按 ABC 分类周期自动生成任务）。

### 7.6 条码与打印（FR-WMS-060~063）
- FR-WMS-060 [M] 物料条码打印（标签模板：物料码+批次+数量二维码）。
- FR-WMS-061 [M] 单据条码（单头二维码供 PDA 扫）。
- FR-WMS-062 [S] 热敏打印机适配（ESC/POS/TSPL 通用方案）。
- FR-WMS-063 [S] 货位条码标签打印。

## 8. 用户故事（关键）

**US-WMS-01 十五秒收货**：作为仓管员，PDA 扫采购到货单二维码，逐行扫物料条码输数量，点确认，账上立即多出这批货。
- AC1 参照到货数量可超收（默认 +5%，参数）；AC2 批次物料必须输/扫批次号；AC3 过账后采购订单行已入库量实时更新；AC4 网络重试不产生双库存。

**US-WMS-02 领料不超发**：作为仓管员，工单领料单要领 100 个，账上可用只有 80，系统能领 80 并提示欠料 20。
- AC1 部分领料允许，欠料登记生成给计划员；AC2 可用量口径=现有−预占−冻结−不良；AC3 领料过账回写工单"已领量"。

**US-WMS-03 盘点闭环**：作为仓管主管，月底我抽盘 A 区，差异自动生成调整单，审核后账实归一。
- AC1 盘点快照与业务并发不互斥（差异=实盘−快照）；AC2 调整单走入库/出库单据通道（不直改台账）；AC3 全程审计留痕。

## 9. 不做清单

波次/任务池高级仓配、月台预约、运输 TMS、AGV/WCS 设备对接、序列号级追溯（Later）、多货主三方物流模式。

## 10. 依赖与风险 / 开放问题

- 依赖：平台（仓库/货位）、ERP（到货/订单/BOM）、MES（报交/领料）。
- 风险：并发过账竞态 → 行级锁+版本校验+流水幂等键三重防护；测试覆盖 100 并发同物料出库。

- OQ-2：货位是否强制？（假设：小厂可"散货仓"无货位模式，参数化）🔶
